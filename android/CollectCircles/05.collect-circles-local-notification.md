אנחנו ממשיכים מן היישום שהושלם בפרקים הקודמים. בשלב הזה נוסיף כפתור בשם `LocalNotif`.
לחיצה עליו תבקש הרשאה, אם היא דרושה, ומיד לאחר קבלת ההרשאה תציג התראה מקומית.

## מה נלמד

- כיצד מצהירים על הרשאת `POST_NOTIFICATIONS`.
- מדוע החל מ־Android 13 צריך גם לבקש את ההרשאה בזמן ריצה.
- מהו `NotificationChannel` ומדוע כל התראה חייבת להשתייך לערוץ.
- כיצד בונים `Notification` ומוסרים אותה למערכת בעזרת `notify`.

לא נשתמש בתזמון או בעבודה ברקע. אין כאן `AlarmManager`,‏ `JobScheduler`,‏ `WorkManager` או
כל מנגנון דומה: אירוע הלחיצה הוא שמציג את ההתראה מיד.

## 1. מצהירים על הרשאת ההתראות

הוסיפו ל־`AndroidManifest.xml`, לפני תגית `application`:

```xml
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
```

הצהרה ב־Manifest אומרת שמותר ליישום לבקש את היכולת הזאת. ב־Android 13 ומעלה היא אינה מספיקה
לבדה: המשתמש צריך לאשר את ההרשאה גם בחלון של מערכת ההפעלה.

## 2. מוסיפים את הכפתור למסך

ב־`activity_main.xml` הוסיפו כפתור מתחת ל־Start:

```xml
<com.google.android.material.button.MaterialButton
    android:id="@+id/localNotifButton"
    android:layout_width="0dp"
    android:layout_height="wrap_content"
    android:layout_marginTop="8dp"
    android:text="@string/local_notification"
    app:cornerRadius="14dp"
    app:layout_constraintEnd_toEndOf="parent"
    app:layout_constraintStart_toStartOf="parent"
    app:layout_constraintTop_toBottomOf="@id/startButton" />
```

כדי שלוח המשחק יתחיל מתחת לכפתור החדש, שנו בו constraint אחד:

```xml
app:layout_constraintTop_toBottomOf="@id/localNotifButton"
```

הוסיפו ל־`strings.xml` את טקסט הכפתור ואת הטקסטים של ההתראה:

```xml
<string name="local_notification">LocalNotif</string>
<string name="notification_channel_name">Circle invitations</string>
<string name="notification_channel_description">Notifications about Collect Circles invitations</string>
<string name="notification_title">Collect Circles</string>
<string name="notification_text">Come collect circles with me!</string>
<string name="notification_permission_denied">Notification permission is required</string>
```

## 3. מרכזים את יצירת הערוץ והצגת ההתראה

צרו מחלקה חדשה בשם `Notifications.java`:

```java
package com.example.collectcircles;

import android.app.Notification;
import android.app.NotificationChannel;
import android.app.NotificationManager;
import android.content.Context;

public final class Notifications {

    private static final String CHANNEL_ID = "circle_invitations";
    private static final int NOTIFICATION_ID = 1;

    private Notifications() {
        // זוהי מחלקת עזר בלבד. אין צורך ליצור ממנה אובייקטים.
    }

    public static void show(Context context) {
        NotificationManager manager = context.getSystemService(NotificationManager.class);

        // כל התראה חייבת להשתייך לערוץ. יצירת ערוץ שכבר קיים אינה יוצרת כפילות,
        // ולכן בטוח לבצע את הפעולה לפני כל הצגה. חשיבות HIGH מאפשרת למערכת
        // להציג את ההתראה באופן בולט, בהתאם להגדרות שבחר המשתמש במכשיר.
        NotificationChannel channel = new NotificationChannel(
                CHANNEL_ID,
                context.getString(R.string.notification_channel_name),
                NotificationManager.IMPORTANCE_HIGH
        );
        channel.setDescription(
                context.getString(R.string.notification_channel_description)
        );
        manager.createNotificationChannel(channel);

        // ה-Builder רק מתאר את ההתראה. הקריאה notify היא הפעולה שמוסרת אותה
        // למערכת Android, ומאותו רגע המערכת אחראית להציג אותה למשתמש.
        Notification notification = new Notification.Builder(context, CHANNEL_ID)
                .setSmallIcon(R.drawable.ic_launcher_foreground)
                .setContentTitle(context.getString(R.string.notification_title))
                .setContentText(context.getString(R.string.notification_text))
                .build();

        manager.notify(NOTIFICATION_ID, notification);
    }
}
```

ה־`CHANNEL_ID` הוא המזהה הפנימי והקבוע של הערוץ. שם הערוץ והתיאור הם הטקסטים שהמשתמש יכול
לראות בהגדרות Android. יצירת אותו ערוץ שוב היא פעולה בטוחה: אם הערוץ כבר קיים, Android לא
יוצר עותק נוסף.

החשיבות `IMPORTANCE_HIGH` מאפשרת הצגה בולטת, אך ההחלטה הסופית נשארת בידי המשתמש והמערכת.
אחרי שערוץ נוצר, המשתמש יכול לשנות את ההגדרות שלו. גם שינוי החשיבות בקוד אינו דורס בחירה
שהמשתמש כבר עשה.

המספר `NOTIFICATION_ID` מזהה את ההתראה. שימוש חוזר באותו מספר מעדכן את אותה התראה במקום
למלא את מגירת ההתראות בעותקים רבים במהלך התרגול.

## 4. מבקשים הרשאה רק כשצריך

הוסיפו ל־`MainActivity` שדה:

```java
private ActivityResultLauncher<String> notificationPermissionLauncher;
```

בתוך `onCreate`, אחרי `setContentView` והגדרת ה־insets, רשמו launcher שמבקש הרשאה ומקבל את
התוצאה:

```java
// החל מ-Android 13 מערכת ההפעלה דורשת אישור מפורש לפני שהיישום יכול
// להציג התראות. ה-launcher פותח את חלון ההרשאה, ומקבל את תשובת המשתמש
// בלי שנצטרך לנהל requestCode או לדרוס פעולה נוספת במחלקה.
notificationPermissionLauncher = registerForActivityResult(
        new ActivityResultContracts.RequestPermission(),
        permissionGranted -> {
            if (permissionGranted) {
                Notifications.show(this);
            } else {
                Toast.makeText(
                        this,
                        R.string.notification_permission_denied,
                        Toast.LENGTH_SHORT
                ).show();
            }
        }
);
```

לאחר ה־listener של כפתור Start, חברו גם את הכפתור החדש:

```java
binding.localNotifButton.setOnClickListener(
        view -> requestPermissionAndShowNotification()
);
```

לבסוף הוסיפו את הפעולה:

```java
private void requestPermissionAndShowNotification() {
    // ב-Android 12 ומטה אין הרשאת התראות בזמן ריצה. ב-Android 13 ומעלה
    // בודקים אם היא כבר ניתנה: אם לא, מבקשים אותה; אם כן, מציגים מיד.
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU
            && checkSelfPermission(Manifest.permission.POST_NOTIFICATIONS)
            != PackageManager.PERMISSION_GRANTED) {
        notificationPermissionLauncher.launch(Manifest.permission.POST_NOTIFICATIONS);
        return;
    }

    Notifications.show(this);
}
```

ב־Android 13 ומעלה הזרימה בלחיצה הראשונה היא:

```text
לחיצה על LocalNotif -> בקשת הרשאה -> אישור המשתמש -> Notifications.show -> התראה
```

בלחיצות הבאות ההרשאה כבר קיימת, ולכן עוברים ישירות אל `Notifications.show`. ב־Android 12
ומטה אין בקשת הרשאה בזמן ריצה, ולכן גם שם ההצגה ישירה.

## 5. בדיקת השלב

1. התקינו והפעילו את היישום.
2. לחצו על `LocalNotif`.
3. ב־Android 13 ומעלה אשרו את בקשת ההרשאה.
4. ודאו שמופיעה התראה בשם **Collect Circles** עם הטקסט **Come collect circles with me!**.
5. לחצו שוב וודאו שההתראה מתעדכנת מיד.

אם דחיתם את ההרשאה, היישום יציג הודעה קצרה ולא יוכל להציג התראה. אפשר לאשר את ההרשאה דרך
הגדרות היישום במכשיר ולנסות שוב.

השלב נבנה ונבדק במכשיר: בקשת ההרשאה הופיעה, ולאחר האישור הכפתור הציג את ההתראה המקומית.
