Until now, every game ended after five circles, and only the best time was saved. Now add long-term progress: each collected circle increases both a balance you can spend later and a counter that never decreases. By the end of the lesson, you can close and reopen the app and see that the counters persist.

## What we will build

- `Circles` — the current balance. In a later chapter, we will be able to spend circles from it.
- `Lifetime` — the number of circles ever collected. A future purchase will not reduce it.
- `Pushers` — the number of small workers we own. It starts at zero; we will learn to buy them later.
- A compact action row, so the new information does not take too much space from the game board.

The short game stays the same: press Start, drag five circles into the target, and get a completion time. We add a layer of progress without replacing that game.

## 1. Create a class that saves the progress

In the **Android** window, under `app > kotlin+java > com.example.collectcircles`, create a **Java Class** named `GameProgress`:

```java
package com.example.collectcircles;

import android.content.SharedPreferences;

public class GameProgress {

    // The keys name each value stored in SharedPreferences.
    private static final String CIRCLES_BALANCE_KEY = "circles_balance";
    private static final String LIFETIME_CIRCLES_KEY = "lifetime_circles";
    private static final String PUSHER_COUNT_KEY = "pusher_count";

    // This preferences object lets us read and save progress on the device.
    private final SharedPreferences preferences;

    // A copy of the progress in memory, for quick use while the application is running.
    private long circlesBalance;
    private long lifetimeCircles;
    private int pusherCount;

    public GameProgress(SharedPreferences preferences) {
        this.preferences = preferences;

        // Load the saved values. If there is no saved value yet, start from scratch.
        circlesBalance = preferences.getLong(CIRCLES_BALANCE_KEY, 0);
        lifetimeCircles = preferences.getLong(LIFETIME_CIRCLES_KEY, 0);
        pusherCount = preferences.getInt(PUSHER_COUNT_KEY, 0);
    }

    // Returns the number of circles available to spend in the shop.
    public long getCirclesBalance() {
        return circlesBalance;
    }

    // Returns the total number of circles collected since the player started playing.
    public long getLifetimeCircles() {
        return lifetimeCircles;
    }

    // Returns the number of Pushers purchased.
    public int getPusherCount() {
        return pusherCount;
    }

    // Updates both counters after the player collects one circle.
    public void recordCollectedCircle() {
        // Stop at the maximum value to prevent overflow into a negative number.
        if (circlesBalance < Long.MAX_VALUE) {
            circlesBalance++;
        }
        if (lifetimeCircles < Long.MAX_VALUE) {
            lifetimeCircles++;
        }

        // Save the new values on the device; apply writes them in the background.
        preferences.edit()
                .putLong(CIRCLES_BALANCE_KEY, circlesBalance)
                .putLong(LIFETIME_CIRCLES_KEY, lifetimeCircles)
                .apply();
    }
}
```

The class holds two types of information:

1. **The state in memory** — the fields used while the application is running.
2. **The saved state** — the values in `SharedPreferences`, which will remain even after closing the application.

The check against `Long.MAX_VALUE` is not expected to be important in a normal game, but it prevents a full counter from overflowing into a negative number.

{: .box-warning}
Do not increment the counters in both `Game` and `MainActivity`. Only `recordCollectedCircle()` changes progress, so each collection adds exactly one circle.

## 3. Report every collected circle

`Game` already returns `true` when a circle has been released entirely within the target. `GameBoardView` should report the event to the Activity immediately, rather than waiting until all five circles have been collected.

{% highlight diff mark_lines="8" %}
+private Runnable onCircleCollected;
private Runnable onGameFinished;

+public void setOnCircleCollectedListener(Runnable listener) {
+    onCircleCollected = listener;
+}

// ACTION_UP
⁞
+if (collected && onCircleCollected != null) {
+    onCircleCollected.run();
+}
if (collected && game.isFinished()
        && onGameFinished != null) {
    onGameFinished.run();
}
{% endhighlight %}

Add the field and the new method, and in `ACTION_UP`, trigger the collection event before the game-finished event. The fifth circle causes two events: first the counters are increased, then the timer stops.

## 4. Connect the progress to `MainActivity`

Add a field:

```java
private GameProgress gameProgress;
```

After creating `preferences` in `onCreate`, load and display the progress:

```diff
preferences = getSharedPreferences(PREFERENCES_NAME, MODE_PRIVATE);
+gameProgress = new GameProgress(preferences);
bestTimeMillis = preferences.getLong(BEST_TIME_KEY, NO_BEST_TIME);
showBestTime();
+showProgress();
```

Inside `onCreate`, after connecting the button `inviteButton` and immediately before the existing endgame event, add the line marked `+`:

```diff
        binding.localNotifButton.setOnClickListener(
                view -> requestPermissionAndShowNotification()
        );
        binding.inviteButton.setOnClickListener(view -> sendInvite());
+       binding.gameBoard.setOnCircleCollectedListener(this::recordCollectedCircle);
        binding.gameBoard.setOnGameFinishedListener(this::finishGame);
    } // This is where onCreate ends
```

Add two methods:

```java
private void recordCollectedCircle() {
    gameProgress.recordCollectedCircle();
    showProgress();
}

private void showProgress() {
    // getString loads the text format circles_balance_format from strings.xml.
    // The second argument replaces %1$d in the pattern with the numerical value of the balance.
    // The prepared text is passed to setText to update the TextView.
    binding.circlesBalanceText.setText(getString(
            R.string.circles_balance_format,
            gameProgress.getCirclesBalance()
    ));

    // in the same way show the total number of circles collected.
    binding.lifetimeCirclesText.setText(getString(
            R.string.lifetime_circles_format,
            gameProgress.getLifetimeCircles()
    ));

    // and finally show the number of Pushers purchased.
    binding.pushersText.setText(getString(
            R.string.pushers_format,
            gameProgress.getPusherCount()
    ));
}
```

{: .box-note}
In `Circles: %1$d`, `%1$` selects the first argument after the string resource ID, and `d` formats it as a decimal integer. Thus, `getString(R.string.circles_balance_format, 7)` returns `Circles: 7`. Keeping the format in `strings.xml` separates text from code and allows translation without changing `MainActivity`.

The Activity does not calculate the new values itself. It asks `GameProgress` to update the state, then displays that updated state.

## 5. Running and testing

Run the application and check:

1. Open the application and make sure that `Circles: 0`, `Lifetime: 0` and `Pushers: 0` appear.
2. Start a game and put one circle in the target. Both circle counters should become 1 immediately.
3. Finish the game. The counters should show 5, and the completion dialog should appear as usual.
4. Start another game and collect a circle. Both the counters should show 6.
5. Close the application completely and open it again. The values 6 and 0 need to be reloaded.
6. Check that the Local notification and Invite buttons still work.
