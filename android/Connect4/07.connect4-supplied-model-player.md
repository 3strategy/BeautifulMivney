בסוף הפרק תוכלו לשחק בלי אינטרנט מול שלושה יריבים שסופקו: מודל מאומן, מודל מוקדם ומודל לא מאומן. אם קובץ חסר או אינו מתאים, המשחק ימשיך עם ההיוריסטיקה ויציג זאת במפורש.

המורה מספק את המימוש המתקדם. MCTS הוא חיפוש שבוחן המשכי משחק ונעזר במודל כדי לבחור מהלך. אין בפרק משימת מימוש של החיפוש, של קידוד הטנזורים או של אימון. מבחינת קוד המשחק שלנו נשאר אותו חוזה: צילום מצב נכנס, פעולה יוצאת.

תחילה הוסיפו את תלות LiteRT ובצעו Sync. לאחר מכן התקינו את [חבילת המורה](#teacher-package), ורק אז חברו את קוד Java של הפרק. החבילה כוללת מודלים וקוד עזר בלבד; אין להעתיק Activity או פרויקט שלם מהמשחק המוגמר.

## מריצים ובודקים

1. שחקו מול כל אחת משלוש הבחירות, כאדום וכצהוב, ללא צורך בחיבור לרשת.
2. סובבו ופתחו מחדש: הבחירה נשמרת לפי ה־ID.
3. בעותק בדיקה, שנו זמנית שם של קובץ מודל ובנו מחדש: המצב צריך לציין Heuristic fallback והמשחק ממשיך. החזירו את הקובץ לפני המשך המסלול.
4. בדקו New game ושינוי מודל בזמן חישוב. תוצאה של המודל הקודם אינה נכנסת למשחק החדש.

המודל הלא מאומן בודק שהחיבור עובד; הוא אינו הוכחה לאיכות משחק. בדיקות המורה מפעילות inference אמיתי, בודקות קובץ חסר ומטא־דאטה שגויה, ובודקות שביטול אינו מפעיל fallback.
