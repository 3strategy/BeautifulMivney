## 3. מחליפים navigation ב-INNER JOIN typed

בפרק 2 התחלנו מכל `Watching` ועברנו דרך האובייקטים הקשורים. כעת נבקש מ-SQLite
לבצע את החיבור ולשלוח בחזרה רק את שלושת הערכים שאנחנו מציגים.

<div markdown="1" class="column">

### SQL

```sql
SELECT s.name, m.title, w.rating
FROM Student s
INNER JOIN Watching w
    ON w.studentId = s.id
INNER JOIN Movie m
    ON m.id = w.movieId
ORDER BY s.id, m.id;
```

</div>
<div markdown="1" class="column">

### Requery typed

```java
data.select(
        StudentEntity.NAME,
        MovieEntity.TITLE,
        WatchingEntity.RATING)
    .from(Student.class)
    .join(Watching.class)
        .on(WatchingEntity.STUDENT_ID
                .eq(StudentEntity.ID))
    .join(Movie.class)
        .on(MovieEntity.ID
                .eq(WatchingEntity.MOVIE_ID))
    .orderBy(StudentEntity.ID, MovieEntity.ID)
```

</div>
</div>

אין כאן שמות טבלאות או עמודות כמחרוזות. כל expression נוצר מ-Java Entity, ולכן
טעות בשם או בטיפוס נעצרת בזמן קומפילציה.

## 4. בונים טפסי דיאלוג קטנים

שלושת הדיאלוגים צריכים כמה Views פשוטים. במקום ליצור שלושה קובצי XML נוספים,
נוסיף פעולות עזר קטנות בתחתית `MainActivity`:

```java
/** Creates one plain single-line dialog input. */
private EditText field(String hint) {
    EditText field = new EditText(this);
    field.setHint(hint);
    field.setSingleLine();
    return field;
}

/** Creates a small label for a dialog field. */
private TextView label(String text) {
    TextView label = new TextView(this);
    label.setText(text);
    return label;
}

/** Creates a Spinner that displays the supplied strings. */
private Spinner spinner(List<String> values) {
    Spinner spinner = new Spinner(this);
    spinner.setAdapter(new ArrayAdapter<>(this,
            android.R.layout.simple_spinner_dropdown_item, values));
    return spinner;
}

/** Stacks dialog controls vertically with density-independent horizontal padding. */
private LinearLayout form(View... fields) {
    LinearLayout form = new LinearLayout(this);
    form.setOrientation(LinearLayout.VERTICAL);
    int padding = (int) (24 * getResources().getDisplayMetrics().density);
    form.setPadding(padding, 0, padding, 0);
    for (View field : fields) form.addView(field);
    return form;
}

/** Shows brief feedback without adding another persistent view to the screen. */
private void toast(String message) {
    Toast.makeText(this, message, Toast.LENGTH_SHORT).show();
}
```

`form(View... fields)` מקבלת מספר משתנה של Views, מסדרת אותם אנכית ומוסיפה
padding שמומר מ-dp לפי צפיפות המכשיר. כך אותה פעולה משרתת את כל הדיאלוגים.

## 7. דיאלוג Watching

הדיאלוג צריך לשמור את האובייקטים שנבחרו, אבל Spinner מציג טקסט. הוסיפו שתי
פעולות שמייצרות תוויות באותו סדר של הרשימות המקוריות:

```java
/** Returns Student names in the same order as their objects. */
private List<String> namesOf(List<Student> students) {
    List<String> names = new ArrayList<>();
    for (Student student : students) names.add(student.getName());
    return names;
}

/** Returns Movie titles in the same order as their objects. */
private List<String> titlesOf(List<Movie> movies) {
    List<String> titles = new ArrayList<>();
    for (Movie movie : movies) titles.add(movie.getTitle());
    return titles;
}
```

כעת הוסיפו את הדיאלוג:

```java
/** Selects Student and Movie choices, then inserts one rated relationship. */
private void showAddWatching() {
    List<Student> students;
    List<Movie> movies;
    try (Result<Student> rows = data.select(Student.class)
            .orderBy(StudentEntity.NAME).get()) {
        students = rows.toList();
    }
    try (Result<Movie> rows = data.select(Movie.class)
            .orderBy(MovieEntity.TITLE).get()) {
        movies = rows.toList();
    }

    Spinner student = spinner(namesOf(students));
    Spinner movie = spinner(titlesOf(movies));
    EditText rating = field("Rating (1-10)");
    rating.setInputType(InputType.TYPE_CLASS_NUMBER);

    new AlertDialog.Builder(this)
            .setTitle("Add Watching")
            .setView(form(label("Student"), student, label("Movie"), movie, rating))
            .setNegativeButton("Cancel", null)
            .setPositiveButton("Add", (dialog, which) -> {
                int score;
                try {
                    score = Integer.parseInt(rating.getText().toString());
                } catch (NumberFormatException e) {
                    toast("Enter a rating from 1 to 10");
                    return;
                }
                if (score < 1 || score > 10) {
                    toast("Enter a rating from 1 to 10");
                    return;
                }
                try {
                    Database.addWatching(data,
                            students.get(student.getSelectedItemPosition()),
                            movies.get(movie.getSelectedItemPosition()), score);
                    showWatchings();
                    toast("Watching added");
                } catch (PersistenceException e) {
                    toast("That student already watched that movie");
                }
            })
            .show();
}
```

ה-index שנבחר בכל Spinner ניגש לאותו index ברשימת ה-entities. לכן
`Database.addWatching` מקבלת Student ו-Movie אמיתיים ולא רק את הטקסט שלהם.

`rating` מוגבלת ל-1–10 לפני ה-insert. אם אותו צמד Student–Movie כבר קיים,
המפתח הראשי המורכב של Watching גורם ל-`PersistenceException`, והאפליקציה מציגה
הודעה במקום לקרוס.

## 8. מריצים את המסלול המלא

בצעו **Build > Make Project**, הריצו ובצעו:

1. לחצו **Add Student**, הזינו `Lia` ולחצו **Add**.
2. לחצו **Add Movie**, הזינו `Coco` ו-`Animation`.
3. לחצו **Add Watching**, בחרו `Lia`, בחרו `Coco`, הזינו `7` ולחצו **Add**.

השורה החמישית צריכה להופיע מיד:

```text
Lia | Coco | 7
```

ב-Logcat אמורות להופיע פעולת insert אחת לכל טבלה ולאחר מכן שאילתה הכוללת:

```sql
inner join Watching ... inner join Movie ...
```

סגרו והריצו שוב. השורה החמישית צריכה להישאר, והפתיחה מחדש צריכה לבצע אפס
inserts.

נסו להוסיף שוב `Lia → Coco`. במקום שורה כפולה אמורה להופיע ההודעה:

```text
That student already watched that movie
```
