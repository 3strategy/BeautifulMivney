ב־**strings.xml** החילו את שינויי האזורים הבאים. שורות `+` נוספות, שורות `-` מוסרות, שורות ההקשר נשארות; `⁞` מסמן אזור קיים שלא הוצג. שימרו את שאר קוד התבנית.

```diff
 <resources>
     <string name="app_name">topics</string>
+    <string name="ball_instruction">Tap the surface to move the bouncing ball. Leave and return to observe the render loop stopping and restarting.</string>
+    <string name="ball_description">Animated bouncing ball game surface. Tap to move the ball.</string>
 </resources>
```
